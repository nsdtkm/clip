# Clip icon

Generated with the built-in image_gen tool. Source artwork: `ClipIcon.png`.
The build script converts the artwork into the standard macOS icon sizes and packages `Clip.icns` in the app bundle.
The menu bar uses the native monochrome `clipboard` symbol so it stays legible in light and dark appearances.

## Generation prompt

Use case: logo-brand. Asset type: production macOS application icon for a minimal clipboard history utility named Clip. Generate one 1024x1024 square PNG, actual transparent outside background. Center a single softly rounded square dark graphite tile occupying about 84% of the canvas. On the tile place one large simple ivory clipboard outline with a small rounded top clip and a single offset sheet outline behind it, suggesting saved copy history. Flat, crisp geometric forms, consistent thick rounded strokes, generous negative space, restrained soft edge shading only on tile. Extremely simple and readable at small sizes. No text, letters, lines of text, numbers, badges, additional symbols, mockup, border frame, or watermark. Front view, perfectly centered. This is the final icon artwork, not a presentation.
