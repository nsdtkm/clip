# Clip

[English](#english) · [Download v0.0.2](https://github.com/nsdtkm/clip/releases/tag/v0.0.2)

Apple Silicon向けの軽量なクリップボード履歴アプリです。Swift / AppKitとmacOS標準のSQLiteだけを使用します。macOS 13以降に対応します。

## ダウンロード・インストール

[Releases](https://github.com/nsdtkm/clip/releases/tag/v0.0.2)から`Clip-v0.0.2-arm64.zip`をダウンロードし、展開した`Clip.app`をApplicationsフォルダーに移動して起動してください。Apple Silicon / macOS 13以降向けです。

このリリースはアドホック署名のみで、Developer ID署名・Appleの公証はありません。初回起動がブロックされた場合、配布元を信頼できることを確認したうえで、システム設定 → プライバシーとセキュリティ →「このまま開く」で許可してください。管理されたMacでは許可できない場合があります。[Appleの案内](https://support.apple.com/102445)

自動貼り付けには、同じ設定内の「アクセシビリティ」でClipを許可してください。既存のClipを使用している場合は終了してから置き換えます。

## ビルド・起動

Command Line Tools（Swift 5.9以降）が必要です。外部パッケージのダウンロードはありません。

```sh
./scripts/build-app.sh
open dist/Clip.app
```

`dist/Clip.app`を固定の場所（例：`/Applications`）へ移動して利用してください。ログイン時起動やアクセシビリティの許可は、移動後のアプリに対して設定してください。生成物はarm64専用で、開発用のアドホック署名です。配布用のDeveloper ID署名・公証は含みません。

## 使い方

1. アプリ起動後、通常どおりテキストまたは画像をコピーします。
2. 貼り付け先の入力欄にカーソルを置き、`⇧⌘V`で履歴を開きます。
3. `↑` / `↓`で選択し、`Enter`またはクリックで貼り付けます。`Esc`で取り消します。
4. 初回の自動貼り付け時は、システム設定 → プライバシーとセキュリティ → アクセシビリティでClipを許可し、再度履歴を開いてください。

メニューバーのクリップボードアイコンから、履歴表示、記録の一時停止、設定、全削除、終了を選べます。履歴で選択した項目は`Backspace`（Macの`delete`キー）で削除します。キーの長押しでは連続削除しません。

履歴ウィンドウは角丸・背景30%透過（不透明度70%）の枠なし表示です。macOS標準の背景ぼかしに、半径3のGaussian Blurを追加しています。文字・画像には透過やぼかしを適用しません。タイトルバー、閉じる／最小化ボタン、説明文は表示しません。`Esc`またはウィンドウ外のクリックで閉じます。

設定のホットキーボタンをクリックし、Command / Control / Optionのいずれかを含むキーの組み合わせを入力すると変更できます（Shiftも併用可能）。OS予約や他アプリとの競合で登録できない場合は、以前の設定を維持します。

ウィンドウ幅は560pt、テキスト行は44pt、画像行は88ptです。画像は最大160 × 72ptの枠内に縦横比を維持して表示し、選択ハイライトは角丸です。

## 保存と制限

- テキストはプレーンテキスト、画像は静止PNGとしてローカルに保存します。
- 保存先：`~/Library/Application Support/Clip/`。SQLiteはメタデータ、`.clip`ファイルはテキスト・画像の実体です。アプリを再起動しても履歴は残ります。
- 最大100件、内容の合計200MiB、1件20MiB。古い順に削除します。DBやサムネイル等のサイズは容量上限に含みません。
- 画像は入力データ20MiB以下・4,000万画素以下に制限し、PNG変換後にも20MiB上限を適用します。画像本体は常駐メモリに保持しません。
- 同じ種類・同じ保存データの内容は1件にまとめ、最新へ移動します。自分で履歴から再コピーした内容は二重登録しません。
- 約500msごとに変更を確認します。その間の連続コピーや、画像処理中の連続コピーはすべて記録できるとは限りません。
- Concealed / Transient / AutoGeneratedとしてマークされた内容は記録しません。すべてのアプリがマークを付けるわけではないため、機密情報を扱う際は記録の一時停止を利用できます。保存内容は暗号化しません。
- 新しいmacOSでクリップボード読み取りの許可を求められた場合は、Clipによるアクセスを許可してください。
- 貼り付け先が画像に対応していれば画像を貼り付けられます。Finderでコピーしたファイルそのものの履歴化、複数項目の同時コピー、アニメーションは対象外です。
- 自動貼り付けは、元アプリが最前面に戻り、修飾キーが離されたことを確認してから⌘Vを送ります。確認できない場合は自動送信を中止し、手動の⌘Vを案内します。
- 検索・同期・OCR・リッチテキスト対応は開発範囲外です。

## 検証

```sh
./scripts/test-store.sh
./scripts/build-app.sh
```

保存テストは外部テストフレームワーク不要です。Unicodeとバイナリの復元、重複の最新化、件数・容量上限、過大データの拒否、個別削除・全削除、孤立ファイルの回収を確認します。

手動確認項目：

- テキストエディタで複数回コピーし、⇧⌘V → ↑↓ → Enterで元の入力位置へ貼り付け。
- 画像をコピーし、サムネイルと画像対応アプリへの貼り付けを確認。
- Esc、クリック、個別削除、一時停止、全削除、再起動後の履歴を確認。
- ホットキーを変更し、再起動後も維持されることを確認。
- アクセシビリティ未許可時の案内、許可後の貼り付けを確認。
- ログイン時起動を設定し、再ログインして確認。
- アクティビティモニタで待機時CPU・メモリと大きな画像処理時のピークを確認。CPU平均1%未満・通常利用時50MB以下は暫定目標で、保証値ではありません。

## English

Clip is a lightweight menu bar clipboard history app for Apple Silicon Macs running macOS 13 or later. It is built with Swift, AppKit, and the system SQLite library, with no third-party package dependencies.

### Download and install

1. Download **Clip-v0.0.2-arm64.zip** from [GitHub Releases](https://github.com/nsdtkm/clip/releases/tag/v0.0.2).
2. Extract the ZIP and move **Clip.app** to **Applications**. Quit any existing instance before replacing it.
3. Open Clip. Its clipboard icon appears in the menu bar; it does not appear in the Dock.
4. Allow Clip in **System Settings → Privacy & Security → Accessibility** to enable automatic pasting.

**This release is ad hoc signed, not Developer ID signed or notarized by Apple.** macOS may block the first launch. If you trust this download, try opening it, then go to **System Settings → Privacy & Security → Open Anyway**. Organization-managed Macs may prevent this override. See [Apple’s instructions](https://support.apple.com/102445). Do not disable system-wide security protections.

If macOS requests clipboard access, allow it to record history. OS permission dialogs follow your system language; Clip’s own UI is in English.

### Usage

- Copy text or a still image as usual.
- Focus the destination app and press **Shift + Command + V** to open history.
- Select an item with **↑ / ↓**, then press **Enter**, or click an item, to paste it into the previous app.
- Press **Backspace / Delete** to remove the selected item. Holding the key does not repeatedly delete items.
- Press **Esc** or click outside the window to dismiss it.
- Use the menu bar to pause/resume recording, clear history, open Settings, or quit.
- In **Settings**, click the shortcut button and enter a combination containing Command, Control, or Option; Shift can also be included. Enable **Launch at Login** if desired.

The history panel is borderless, with rounded corners and a 30% transparent background. A radius-3 Gaussian blur is added to the native background material. History text and images stay sharp.

The panel is 560pt wide, with compact 44pt text rows and larger 88pt image rows. Image previews fit within 160 × 72pt while preserving their aspect ratio. Selection highlights have rounded corners.

### Storage and limits

- Plain text and still images are stored locally in `~/Library/Application Support/Clip/` and survive restarts. SQLite holds metadata; `.clip` files hold payloads.
- Up to **100 items**, **200MiB total payload**, and **20MiB per item**. Older entries are removed when a limit is reached. Database overhead is not included in this budget.
- Images are converted to PNG. Input images are limited to 20MiB and 40 million pixels; the resulting PNG must also fit the 20MiB limit. Full-size images are not kept resident in memory.
- Identical stored content of the same type is deduplicated and moved to the top. Reusing a history item does not create a duplicate.
- Clipboard changes are checked approximately every 500ms. Rapid copies and copies made during image processing may be missed.
- Items marked Concealed, Transient, or AutoGenerated are skipped. Not all apps provide these markers. Storage is **not encrypted**; pause recording when appropriate.
- Image pasting requires support from the destination app. Finder file copies, multi-item copies, and animations are not supported.
- Automatic paste waits for the original app to regain focus and modifier keys to be released. If it cannot confirm the destination, the item remains copied for manual pasting with Command + V.
- **Search, sync, OCR, and rich text are outside the project’s scope.**

### Build and verify

Install Apple’s Command Line Tools with Swift 5.9 or later, then run:

```sh
./scripts/test-store.sh
./scripts/build-app.sh
open dist/Clip.app
```

The build script creates an arm64-only, ad hoc signed `.app` with its icon bundled. Storage checks cover Unicode and binary round trips, duplicate promotion, count/size limits, oversized item rejection, deletion, and orphan-file cleanup. UI behavior, Accessibility permissions, and login startup require manual verification on the target Mac.

### Source layout

- `Sources/Clip/App.swift`: menu bar, history panel, clipboard monitoring, image processing, automatic paste, and settings.
- `Sources/Clip/HistoryStore.swift`: persistence, deduplication, and storage limits.
- `Sources/Clip/HotKey.swift`: global shortcut registration and shortcut recorder.
- `scripts/build-app.sh`: release build, icon packaging, and ad hoc signing.
- `Assets/README.md`: icon generation method and original prompt.
