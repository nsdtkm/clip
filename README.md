# Clip

Apple Silicon向けの軽量なクリップボード履歴アプリです。Swift / AppKitとmacOS標準のSQLiteだけを使用します。macOS 13以降に対応します。

## ビルド・起動

Command Line Tools（Swift 5.9以降）が必要です。外部パッケージのダウンロードはありません。

```sh
./scripts/build-app.sh
open dist/Clip.app
```

`dist/Clip.app`を固定の場所（例：`/Applications`）へ移動して利用してください。ログイン時起動やアクセシビリティの許可は、移動後のアプリに対して設定してください。生成物はarm64専用で、開発用のアドホック署名です。配布用のDeveloper ID署名・公証は含みません。

## 使い方

1. アプリ起動後、通常どおりテキストまたは画像をコピーします。
2. 貼り付け先の入力欄にカーソルを置き、`⇧⌘V`で履歴を開きます。
3. `↑` / `↓`で選択し、`Enter`またはクリックで貼り付けます。`Esc`で取り消します。
4. 初回の自動貼り付け時は、システム設定 → プライバシーとセキュリティ → アクセシビリティでClipを許可し、再度履歴を開いてください。

メニューバーのクリップボードアイコンから、履歴表示、記録の一時停止、設定、全削除、終了を選べます。履歴で選択した項目は`Backspace`（Macの`delete`キー）で削除します。キーの長押しでは連続削除しません。

履歴ウィンドウは角丸・背景70%透過（不透明度30%）の枠なし表示です。macOS標準の背景ぼかしに、半径3のGaussian Blurを追加しています。文字・画像には透過やぼかしを適用しません。タイトルバー、閉じる／最小化ボタン、説明文は表示しません。`Esc`またはウィンドウ外のクリックで閉じます。

設定のホットキーボタンをクリックし、Command / Control / Optionのいずれかを含むキーの組み合わせを入力すると変更できます（Shiftも併用可能）。OS予約や他アプリとの競合で登録できない場合は、以前の設定を維持します。

## 保存と制限

- テキストはプレーンテキスト、画像は静止PNGとしてローカルに保存します。
- 保存先：`~/Library/Application Support/Clip/`。SQLiteはメタデータ、`.clip`ファイルはテキスト・画像の実体です。アプリを再起動しても履歴は残ります。
- 最大100件、内容の合計200MiB、1件20MiB。古い順に削除します。DBやサムネイル等のサイズは容量上限に含みません。
- 画像は入力データ20MiB以下・4,000万画素以下に制限し、PNG変換後にも20MiB上限を適用します。画像本体は常駐メモリに保持しません。
- 同じ種類・同じ保存データの内容は1件にまとめ、最新へ移動します。自分で履歴から再コピーした内容は二重登録しません。
- 約500msごとに変更を確認します。その間の連続コピーや、画像処理中の連続コピーはすべて記録できるとは限りません。
- Concealed / Transient / AutoGeneratedとしてマークされた内容は記録しません。すべてのアプリがマークを付けるわけではないため、機密情報を扱う際は記録の一時停止を利用できます。保存内容は暗号化しません。
- 新しいmacOSでクリップボード読み取りの許可を求められた場合は、Clipによるアクセスを許可してください。
- 貼り付け先が画像に対応していれば画像を貼り付けられます。Finderでコピーしたファイルそのものの履歴化、複数項目の同時コピー、アニメーションは対象外です。
- 自動貼り付けは、元アプリが最前面に戻り、修飾キーが離されたことを確認してから⌘Vを送ります。確認できない場合は自動送信を中止し、手動の⌘Vを案内します。
- 検索・同期・OCR・リッチテキスト対応は開発範囲外です。

## 検証

```sh
./scripts/test-store.sh
./scripts/build-app.sh
```

保存テストは外部テストフレームワーク不要です。Unicodeとバイナリの復元、重複の最新化、件数・容量上限、過大データの拒否、個別削除・全削除、孤立ファイルの回収を確認します。

手動確認項目：

- テキストエディタで複数回コピーし、⇧⌘V → ↑↓ → Enterで元の入力位置へ貼り付け。
- 画像をコピーし、サムネイルと画像対応アプリへの貼り付けを確認。
- Esc、クリック、個別削除、一時停止、全削除、再起動後の履歴を確認。
- ホットキーを変更し、再起動後も維持されることを確認。
- アクセシビリティ未許可時の案内、許可後の貼り付けを確認。
- ログイン時起動を設定し、再ログインして確認。
- アクティビティモニタで待機時CPU・メモリと大きな画像処理時のピークを確認。CPU平均1%未満・通常利用時50MB以下は暫定目標で、保証値ではありません。

## 構成

- `Sources/Clip/App.swift`：メニューバー、履歴UI、クリップボード監視、画像処理、自動貼り付け、設定。
- `Sources/Clip/HistoryStore.swift`：SQLite、内容ファイル、重複排除と保存上限。
- `Sources/Clip/HotKey.swift`：グローバルホットキーの登録と設定用入力。
- `scripts/build-app.sh`：arm64ビルド、appバンドル生成、開発用署名。

UIのメニュー・設定・通知は英語表記です。コピーした内容は元の言語のまま表示します。macOSの権限ダイアログはシステムの言語設定に従います。

アプリアイコンは`Assets/ClipIcon.png`からビルド時に各サイズのmacOSアイコンへ変換します。生成方法とプロンプトは`Assets/README.md`に保存しています。
